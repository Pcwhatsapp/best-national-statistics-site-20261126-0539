NusaStat — a national statistics site for Indonesia: population, economy, prices, labour and regions, with real figures, interactive Canvas charts, sortable tables and sources for every number. Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the site is plain static files under `app/` (no build step, no network requests) and works on desktop and on a phone. `main.ts` hands it in: it copies `app/` and `screenshots/` to `/output` and writes `/output/dossier.json`.
